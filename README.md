# 绷不住街机厅

新街口街机独立试玩版。入口为 index.html，可通过 GitHub Pages 发布。

## 发布

1. 在 GitHub 创建公开仓库，例如 xinjiekou-arcade。
2. 将 index.html 和 .nojekyll 上传到仓库根目录，不要只上传 ZIP。
3. 仓库 Settings → Pages → Deploy from a branch → main → /(root) → Save。
4. 等待部署完成，从 Pages 页面复制实际网址，放到 B站视频简介或置顶评论。

通常网址：https://你的用户名.github.io/xinjiekou-arcade/

此包是独立网页街机，不包含完整 UE 城市工程。
